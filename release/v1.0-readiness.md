## Provenance note (DOD-REL-06)

The release workflow attempts a build-provenance attestation on every release and states the outcome in the release
notes. For v0.3.0 (run 40136468900) GitHub answered: "Feature not available for user-owned private repositories". The
SBOM, SHA256SUMS and the audit gate are produced; provenance is waived (below).
